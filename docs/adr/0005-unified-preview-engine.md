# 注入模式与独立工作台共用同一套预览引擎

> **部分被 ADR-0006 取代。** "共用同一套预览引擎"仍成立，但独立工作台不再用 iframe 承载目标页，改为打开新标签页并附加调试器。下文关于 iframe 的部分已失效。

方式 2（直接 DOM 变换）确定后，独立工作台面临选择：保留自己的 iframe 渲染逻辑，或与注入模式共用引擎。

决定：只维护一套预览引擎。注入模式下它直接作用于当前页 DOM；独立工作台是一个极简页面，内含一个全尺寸 iframe 加载用户输入的 URL，预览引擎作用于该 iframe。两者共享所有设备外壳、安全区、缩放与旋转变换代码。

理由：避免两套渲染逻辑并行演化导致的 bug 与维护负担。独立工作台在此定位下已退化为"输入 URL 的兜底入口"，不再值得拥有独立实现。
