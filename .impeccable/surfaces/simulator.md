# Surface Brief: Device Simulator UI

<!-- impeccable:surface-schema 1 -->

## Mode

Operate

## Form

seed:ff92e30b404c7e99 / Studio (architect's model, chosen via decision page)

## Direction Contract

### World

建筑师工作台：白色卡纸模型、Muji 产品目录、Dieter Rams 的 Braun。被预览的页面是唯一主角，所有 UI 无色隐形，只在需要时显现。

### Palette

- 背景：纯白 `#FFFFFF`
- 文字与主线条：深炭 `#111111`
- 次级文字：`#6B7280`
- 分隔线：`#E5E7EB`（细如发丝的 1px)
- 主强调：单一暖橙 `#FF5500`（仅用于主按钮、选中态、活动指示）
- 状态：翠绿 `#059669`（已注入）、琥珀 `#D97706`（警告）、朱红 `#DC2626`（错误）

### Typography

- 界面：Inter,4 档（11px 标签 / 13px 正文 / 16px 强调 / 24px 设备名）
- 字重：400 正文 / 500 强调 / 600 设备名
- 行高：1.5 正文 / 1.2 标题

### Signature Move

**设备即雕塑**：设备框是页面上唯一有"物质感"的元素——柔和的投影（`0 8px 32px rgba(0,0,0,0.08)`）让它浮在白色背景上，像卡纸模型放在工作台上。其他所有 UI（工具栏、按钮、面板）是无色的、隐形的——透明背景、无边框，只在 hover 时才显现 1px 细线边界。

### First Viewport

- 中央：设备框带柔和投影，占 90% 视觉权重
- 顶部：1px 分割线，下方是几乎透明的工具栏（设备选择、旋转、缩放、居中、退出）
- 无侧边栏、无状态栏；设备规格通过 hover 设备框右上角的 ⓘ 图标弹出
- 当前 URL 显示在工具栏最左，字号极小（11px)

### Craft Bar

Linear、Raycast、Vercel Dashboard 同家族的工艺水准：每个间距都是 4 的倍数，每个字号都来自同一套 scale，没有任何"差不多"的视觉效果。

### Honest Risk

这是工具类 UI 的"安全选择"，最容易被预测。避免平庸的关键在于：UI 的"隐形"必须做到彻底——如果工具栏背景有 5% 灰、如果按钮有默认边框，就滑向"普通灰底工具"而非"设备即雕塑"。

## Scope

- **In scope**:
  - 注入模式覆盖层 UI（设备框、工具栏、ⓘ 弹层）
  - 独立工作台单页（URL 输入 + 预览区）
  - 设备选择面板（hover 工具栏"设备名"时弹出）
  - 自定义设备表单（极简 5 字段）
- **Out of scope**:
  - logo / 图标设计（后续单独任务）
  - 设置页（v1 无设置）
  - 多设备对比、截图、导入导出（已砍）

## Success Looks Like

用户注入后，目光第一时间落在设备框里的页面上，而不是工具栏；工具栏在不需要时几乎不可见，在需要时（鼠标移上去）立刻清晰；整个界面没有任何"装饰性"元素，每一个像素都在为"看清被预览页面"服务。
